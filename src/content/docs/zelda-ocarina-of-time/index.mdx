Lançado em 1998 para Nintendo 64, *Ocarina of Time* acompanha Link da infância à vida adulta numa viagem no tempo para impedir Ganondorf de dominar Hyrule.

:::caution[Qual versão este guia cobre]
Este guia segue o **original de Nintendo 64** (também vale para o relançamento no Nintendo Switch Online). A versão **3D do 3DS** tem os mesmos locais, mas os botões da ocarina são outros. O **remake de 2026** muda a posição de algumas Peças de Coração. Se você joga o remake, confira cada local no seu jogo.
:::
