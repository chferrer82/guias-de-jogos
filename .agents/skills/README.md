# Skills de desenvolvimento

Estas skills do [ECC de Affaan Mustafa](https://github.com/affaan-m/ECC) estão disponíveis no escopo do repositório para o Codex. Os arquivos vêm da [revisão 4adeee6](https://github.com/affaan-m/ECC/tree/4adeee6732a12d1540f49a4d50a38ce8c97f9a53) e cada pasta inclui a licença MIT original.

| Skill | Aplicação no portal |
| --- | --- |
| `research-ops` | Conferir regras do jogo digital e registrar fonte, versão e grau de confiança |
| `verification-loop` | Revisar o diff e verificar o artefato, os testes e, quando publicado, o ambiente de destino |
| `e2e-testing` | Testar interações críticas e falhas de carregamento em Chromium |

Para atualizar uma skill, compare o `SKILL.md` e os arquivos relacionados com uma nova revisão oficial. Atualize o link da revisão e mantenha a licença junto da cópia.
